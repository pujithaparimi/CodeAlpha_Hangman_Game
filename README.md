# Hangman Game

## Overview

Hangman Game is a text-based word guessing game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

* Random word selection
* Letter-by-letter guessing
* Input validation
* Wrong guess tracking
* Win and Lose conditions
* User-friendly console interface

## Technologies Used

* Python
* Random Module
* Loops
* Conditional Statements
* Lists and Strings

## How to Run

1. Clone the repository
2. Open the project folder
3. Run the following command:

```bash
python hangman.py
```

## Sample Gameplay

* User guesses letters one at a time
* Correct letters are revealed
* Maximum 6 wrong guesses allowed
* Game ends with Win or Lose message
